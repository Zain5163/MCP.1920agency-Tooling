Meta refused my first live campaign with one sentence:

"Dynamic creative ads can only be created under dynamic creative ad sets."

Worth knowing if you run Meta ads, by hand or with any tool.

The ad had five versions of the primary text, so Meta treats it as a dynamic creative: it rotates the texts and learns which works for whom.

That comes with two rules that are easy to miss:

1. The ad set has to be marked for dynamic creative when it is created. You can't switch it on later. Meta will not convert an existing ad set.
2. That ad set can hold only one ad.

So if you build the ad set first and then try to add a multi-text ad, it fails. The only fix is a new ad set.

What I find interesting is that the test environment never showed this. My sandbox tests created the creatives on their own and never made a real ad from them, so the rule never came up. It only appeared on a real account.

What I changed:
→ an ad set that will hold a multi-text ad is created as dynamic from the start
→ a second ad beside a dynamic creative is refused before anything is built
→ the failed attempt (paused, never spent) was deleted after checking its name, status and spend

If you've seen this error in Ads Manager, that's the cause.
