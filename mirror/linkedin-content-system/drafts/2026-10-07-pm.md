## Post text

"You don't have the required permission to access this profile."

If you've set up Meta ads through Business Manager, a system user or any API tool, you've probably seen this error (code 10).

I spent four attempts guessing at it. Three questions answered it.

The lesson: Meta's permission errors name the symptom, never the cause. They don't tell you which identity is acting or which link between assets is missing.

So stop guessing and ask:

1. Who is this token, really? It may not be the user you think it is.
2. Which Pages can it reach, and with which tasks?
3. Which Pages will this ad account actually promote?

In my case the token belonged to a different identity from the one I'd been assigning assets to. Separately, the ad account had no Page it was allowed to promote.

That second one catches people: assigning a Page to a user in Business Manager and linking a Page to an ad account are separate things. Doing one doesn't do the other.

Slides below. Save it for the next time code 10 shows up.

## Slides

1. **Meta "code 10": stop guessing.** "You don't have the required permission to access this profile."
2. **Why it's confusing:** the error names the symptom. It never names the identity or the missing link.
3. **Question 1, who is the token?** Check which user or system user it really belongs to. Test tokens and real system users are different identities.
4. **Question 2, what can it reach?** Which Pages, with which tasks (for example, advertise only, or full).
5. **Question 3, what will the ad account promote?** If that list is empty, a creative naming your Page will fail.
6. **The trap:** a Page assigned in Business Manager is not the same as a Page linked to the ad account. You need both.
