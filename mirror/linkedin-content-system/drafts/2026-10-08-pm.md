If you're using AI to make ad images, check the shape before you check the style.

When I added image generation to what I'm building, I checked what each model could actually produce. It's not the same everywhere:

→ Gemini 3.1 Flash Image could make every shape I needed for Meta ads, so it's the default
→ OpenAI's GPT Image 2 had no 4:5, which is the Feed shape, so a request for it is refused before anything is charged
→ none of the models listed made a true 1.91:1 landscape, so landscape is refused rather than faked by cropping 16:9

(That's what I found last week. Models change fast, so check again before you rely on it.)

Three rules I now apply to every AI ad image:

1. No text in the image. Image models still misspell words, and copy belongs in the ad's text fields, where you can edit and test it.
2. Compose for the placement. For 9:16 Stories and Reels, keep the top and bottom clear, because the app's buttons and profile name sit there.
3. Put a daily cap on generation. Each image costs only cents, so approving them one by one makes no sense. A spending cap in code is the right control.

The image is the cheap part. A wrong shape that never gets served is the expensive part.
