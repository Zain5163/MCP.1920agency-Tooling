## Post text

If an AI can launch your ads, who approves the spend?

A lot of AI ad tools answer that with a confirmation flag, and the AI itself can set it.

That isn't an approval. It's the model agreeing with itself.

Here's how I'm handling it in what I'm building. Three gates, in this order, for anything that can spend:

1. Validation. If Meta would reject it, or it breaks a rule, it stops here.
2. The spend ceiling. Checked against everything the account already spends, not just this campaign.
3. Approval. A person sees the plan and the real cost. Only then is a token issued, tied to that exact plan. If anything changes afterwards, even the budget, the token stops working.

And two rules:
→ everything is created paused, so nothing spends while you look at it
→ pausing needs no approval at all, because stopping spend should never wait

The slides walk through it.

If you're letting AI anywhere near a client's budget, this is the question to ask any tool.

## Slides

1. **An approval an AI cannot forge.** How I gate ad spend.
2. **The problem:** "confirm: true" is something the model can type itself. That's not a human decision.
3. **Gate 1, validation:** refused before anything is built if Meta would reject it.
4. **Gate 2, the ceiling:** daily and monthly limits across the whole account. No limit set means nothing that spends will run.
5. **Gate 3, approval:** a person sees the plan and the cost, and gets a token tied to exactly that plan. Change one thing and the token is void.
6. **Lifecycle:** created paused → approved → ads and ad sets switched on → campaign switched on last. Refused if Meta rejected any ad.
7. **Stopping is free:** pause has no gate. A wrong pause costs some delivery. A slow pause costs money.
